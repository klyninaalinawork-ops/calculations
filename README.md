# Calc.desk

Локальний дашборд для перегляду й управління калькуляціями з Excel-файлів у корені проєкту.

## Запуск

```bash
npm install
npm run dev
```

Vite покаже адресу локального дашборда в терміналі.

## Оновлення даних

Після додавання або заміни файлів `Калькуляція *.xlsx` у корені проєкту виконайте:

```bash
npm run data:refresh
```

Парсер формує `public/data/calculations.json`; для цього потрібен Python 3. Статуси та нотатки зберігаються у локальному сховищі браузера і не змінюють початкові Excel-файли.

## Перевірка production-збірки

```bash
npm run build
```
